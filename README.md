# Portfolio — Полякова Ксения

Одностраничный сайт-портфолио графического дизайнера и UX/UI специалиста.
Стиль: **glassmorphism** + **живой главный экран** с интерактивными эффектами.

## 🚀 Стек

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox / Grid, CSS-переменные, `clamp()`, `backdrop-filter`
- **Vanilla JavaScript (ES6+)** — без фреймворков и библиотек

## 🎬 Живой главный экран

| Эффект | Что делает |
|---|---|
| **Кинетическая типографика** | Буквы `PORTFOLIO` отталкиваются, наклоняются и растягиваются от курсора. При скролле — разъезжаются и исчезают, открывая имя |
| **3D-кубы** | Декоративные кубы реагируют на мышь: наклон, глубина, свечение |
| **Контекстный курсор** | Плашка со словами **ОТКРЫТЬ / НАПИСАТЬ / УВЕЛИЧИТЬ** появляется над элементами `[data-cursor]` |
| **Шлейф из частиц** | Голубые (тёмная тема) / синие (светлая) светящиеся точки + линии на `<canvas>` |

Все эффекты **автоматически отключаются**:
- на тач-устройствах (`@media (hover: none)`)
- при `prefers-reduced-motion: reduce`

## ⚙️ Реализованный функционал (JavaScript)

1. Переключение светлой/тёмной темы с сохранением в `localStorage`.
2. Анимация появления при скролле (Intersection Observer API).
3. Валидация формы обратной связи (имя, email, сообщение).
4. Бургер-меню для мобильных с закрытием по Escape.
5. **Кинетическая типографика** — реакция букв на курсор и скролл.
6. **Интерактивные 3D-кубы** — наклон и подсветка от курсора.
7. **Контекстный курсор** — плашка с подписью по `[data-cursor]`.
8. **Шлейф из частиц** — canvas + `requestAnimationFrame`.

## 🎨 Дизайн

- Тёмная тема по умолчанию, светлая — по кнопке.
- **Glassmorphism**: `backdrop-filter: blur(16px) saturate(180%)` + блик сверху.
- Цветные пятна на фоне секций, чтобы стекло «играло».
- Шрифты: **Unbounded** (заголовки) + **Montserrat** (текст).
- Палитра: `#0a0a0a`, `#00d2ff`, `#2563eb`.

## 🧠 Использование ИИ

**Инструмент:** ChatGPT (OpenAI, GPT-5)

**Задачи:**
- Генерация структуры HTML и mobile-first верстки.
- Подбор цветовой схемы и CSS-градиентов для 3D-декора.
- Написание логики темы, Intersection Observer, валидации формы.
- Интеграция glassmorphism во все интерактивные блоки.
- Реализация кинетической типографики, интерактивных кубов, контекстного курсора и canvas-шлейфа.

**Один существенный запрос:**

> «Сделай кинетическую типографику: буквы заголовка должны отталкиваться от курсора, наклоняться, растягиваться и разъезжаться при скролле. Только Vanilla JS, без библиотек.»

**Результат и проверка:** ИИ выдал разбиение слова на `<span>`, расчёт расстояния от курсора до каждой буквы и `requestAnimationFrame`-цикл. Проверил в Chrome — буквы корректно отталкиваются и разъезжаются при скролле; проблем с производительностью нет.

**Что исправил самостоятельно:**
1. Добавил `effectsEnabled` — чтобы все 4 эффекта отключались на мобильных и при `reduce-motion`.
2. Ограничил количество частиц (`MAX_PARTICLES = 90`) и `devicePixelRatio` (max 2) — чтобы canvas не грузил слабые устройства.
3. Для светлой темы переключил `mix-blend-mode` с `screen` на `multiply` — иначе шлейф был не виден.
4. Сделал цвет частиц зависимым от темы через `getColor()`.
5. Добавил `updateRects()` — иначе при ресайзе буквы теряли свои опорные координаты.

## ▶️ Запуск

1. Скачайте файлы в одну папку, создайте рядом `images/` с фото.
2. Откройте `index.html` в браузере.

Или через локальный сервер:

```bash
python -m http.server 8000
# затем http://localhost:8000
```
